# 初始化中的窄化转换

## 问题

C++ 花括号初始化会阻止窄化转换，但圆括号初始化会静默截断。

## 示例

```cpp
// 花括号初始化会报错
int x{3.14};  // 错误：窄化转换

// 圆括号初始化静默截断
int x(3.14);      // OK, x = 3（被截断）
int y = (3.14);   // OK, y = 3（被截断）

// 隐式截断
long long big = 300;
char c = big;          // 警告，但能编译
char c2{big};          // 错误：窄化转换
```

## 为什么重要

窄化转换会静默丢失数据。这在不同大小的整数类型之间尤其危险。

```cpp
uint8_t a = 256;       // 回绕到 0（某些编译器无警告）
uint8_t b = uint8_t(256);  // 也回绕到 0

int16_t negative = -1;
uint16_t positive = negative;  // 回绕到 65535
```

## 预防措施

- 始终使用花括号初始化：`int x{value};`
- 使用 `-Wconversion` 和 `-Wsign-conversion` 编译
- 当截断是有意时使用显式类型转换
- 优先使用 `static_cast` 而非隐式窄化

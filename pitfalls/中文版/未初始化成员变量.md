# 未初始化成员变量

## 问题

在 C++ 中，成员变量只对某些类型进行零初始化。
对于 POD 类型（int, float, 指针），未初始化意味着它们包含垃圾值。

## 示例

```cpp
class Bad {
    int x;         // 未初始化！
    float y;       // 未初始化！
    int* ptr;      // 未初始化！
};

Bad b;
// b.x, b.y, b.ptr 都有垃圾值
// 使用它们是未定义行为
```

```cpp
class Good {
    int x = 0;         // 零初始化
    float y = 0.0f;    // 零初始化
    int* ptr = nullptr; // 空初始化
    std::string name_;  // 默认构造（空字符串）
};
```

## 为什么重要

未初始化变量是 bug 的主要来源，这些 bug 在不同的编译器、平台
甚至优化级别下表现不同。在 debug 模式下正常的 bug 可能在
release 模式下崩溃。

## 预防措施

- 始终在声明时初始化成员变量
- 使用类内成员初始化器（NSDMI）：`int x = 0;`
- 启用编译器警告：`-Wall -Wuninitialized`
- 当成员有初始化器时使用 `= default` 构造函数
- 对于简单数据类型优先使用 `struct` 和默认初始化器

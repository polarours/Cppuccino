# Cppuccino v1.0.0

One C++ idea, in two languages, with runnable proof.

## What is in the box

- **140 articles** — 70 English + 70 Chinese, covering ownership, modern C++,
  design patterns, architecture, systems, performance and tooling.
- **74 pitfalls** — 37 English + 37 Chinese, each with a failure mode and a
  repair.
- **161 runnable examples** — compiled and run in CI, not pseudocode.
- **151 projects across 43 stages** — every project builds and has at least
  three tests; **975 tests** in total.
- **Arcade** — 386 quests across six worlds, with progress saved locally.
- **Four Boss fights** driven by real sanitizer output: dangling pointer,
  iterator invalidation, data race and double free.
- **UB Camp + Proof Gate** — a four-stop route that ends in a 3/3 proof
  challenge, not a badge you get for reading.
- **Interactive Labs** — lifetime, iterator invalidation, data race and double
  free experiments embedded in the articles.

## Site and accessibility

- English and Chinese share one source of truth; no duplicated article trees.
- Chinese pages ship `lang="zh-CN"` in the static HTML and keep it during
  Material instant navigation.
- Fonts are self-hosted Latin WOFF2 subsets. The site makes **zero** requests
  to Google Fonts; Chinese text uses the reader's system CJK font.
- Every generated page has a real description, Open Graph and Twitter card.
- `robots.txt`, `sitemap.xml` and a recovery-oriented `404.html` are included.

## Engineering

- GitHub Actions are pinned by commit SHA; Dependabot watches the pins and the
  docs toolchain.
- Docs dependencies are locked (`mkdocs==1.6.1`, `mkdocs-material==9.8.2`).
- Build shards use ccache; Pages caches pip downloads.
- `coverage (tinyshell)` publishes a gcovr XML report as a workflow artifact.
- `tools/run_all_checks.sh` is the single local entry point CI also runs.

# 左值引用

## 什么是左值引用？

左值引用（`T&`）是绑定到具有身份的对象的引用——这些对象有名字、在内存中占据可识别的位置，并且在单个表达式之外持续存在。

```cpp
int x = 42;
int& ref = x;    // OK：x 是左值
ref = 100;       // 直接修改 x

// int& bad = 42;  // 错误：42 是右值
```

## 核心特性

### 1. 绑定规则

左值引用只能绑定到左值（`const` 左值引用有例外）：

```cpp
int x = 10;
int& r1 = x;       // OK：左值绑定到左值引用
// int& r2 = 42;   // 错误：非 const 左值引用不能绑定到右值

const int& r3 = 42;  // OK：const 左值引用可以绑定到右值
```

### 2. 不能重新绑定

一旦初始化，左值引用始终指向同一个对象：

```cpp
int x = 10;
int y = 20;
int& ref = x;
ref = y;          // 这修改了 x，而不是将 ref 重新绑定到 y
// ref 仍然指向 x，x 的值现在是 20
```

### 3. 必须初始化

左值引用在声明时必须初始化：

```cpp
int x = 10;
int& ref = x;     // OK
// int& bad;       // 错误：未初始化的引用
```

## 常见用例

### 函数参数

左值引用允许函数修改其参数：

```cpp
void increment(int& value) {
    ++value;
}

int main() {
    int x = 5;
    increment(x);  // x 现在是 6
}
```

### 避免拷贝

通过引用传递大型对象以避免昂贵的拷贝：

```cpp
void process(const std::string& str) {
    // 只读访问，无需拷贝
    std::cout << str << '\n';
}
```

### 返回多个值

使用引用来"返回"多个值：

```cpp
void divide(int dividend, int divisor, int& quotient, int& remainder) {
    quotient = dividend / divisor;
    remainder = dividend % divisor;
}
```

## 常见陷阱

### 悬垂引用

当引用的对象被销毁时，引用变成悬垂引用：

```cpp
int& getRef() {
    int local = 42;
    return local;  // 错误：返回局部对象的引用
}

int& ref = getRef();  // 悬垂引用！
```

### 模板中的意外拷贝

转发引用与左值引用不同：

```cpp
template <typename T>
void process(T& arg) {
    // 只接受左值
}

template <typename T>
void process(T&& arg) {
    // 同时接受左值和右值（转发引用）
}
```

## 左值引用与指针对比

| 特性 | 左值引用 | 指针 |
|------|----------|------|
| 初始化 | 必须 | 可选 |
| 重新绑定 | 不允许 | 允许 |
| 可空性 | 不能为 null | 可以为 null |
| 语法 | 直接访问 | 需要解引用 |
| 安全性 | 更安全 | 更灵活 |

## 总结

- 左值引用绑定到具名对象
- 初始化后不能重新绑定
- 使用 `const T&` 进行只读访问和接受右值
- 避免返回局部对象的引用
- 左值引用比指针更安全，但灵活性较低

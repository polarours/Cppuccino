# 右值引用

## 什么是右值引用？

右值引用（`T&&`）是绑定到临时对象的引用——这些对象即将被销毁、没有名字，通常出现在赋值表达式的右侧。

```cpp
int x = 42;
int&& rref = 42;      // OK：42 是右值
int&& rref2 = x + 1;  // OK：x + 1 产生临时对象

// int&& bad = x;      // 错误：x 是左值
```

## 核心特性

### 1. 绑定规则

右值引用只能绑定到右值（转发引用有特殊规则）：

```cpp
int x = 10;
// int&& r1 = x;      // 错误：x 是左值
int&& r2 = 42;        // OK：42 是右值
int&& r3 = x + 1;     // OK：临时结果

// 例外：转发引用
template <typename T>
void wrapper(T&& arg);  // 可以绑定到左值和右值
```

### 2. 启用移动语义

右值引用允许从临时对象"窃取"资源：

```cpp
class Buffer {
    int* data;
    size_t size;
public:
    Buffer(Buffer&& other) noexcept
        : data(other.data), size(other.size) {
        other.data = nullptr;
        other.size = 0;
    }
};
```

### 3. 生命周期延长

绑定到右值引用的临时对象具有延长的生命周期：

```cpp
{
    const int&& ref = 42;  // 临时对象存活到作用域结束
    // ref 在这里是有效的
}
```

## 移动语义

### 问题

在 C++11 之前，从函数返回大型对象需要昂贵的拷贝：

```cpp
std::vector<int> createVector() {
    std::vector<int> result(1000);
    // ... 填充 result
    return result;  // 昂贵的拷贝！
}
```

### 解决方案

移动语义允许转移资源而不是拷贝：

```cpp
std::vector<int> createVector() {
    std::vector<int> result(1000);
    // ... 填充 result
    return result;  // 移动（或 NRVO）代替拷贝
}
```

### std::move

`std::move` 并不移动任何东西——它只是将左值转换为右值引用：

```cpp
int x = 42;
int&& rref = std::move(x);  // 现在可以移动 x 的资源
```

## 常见用例

### 移动构造函数

将资源从一个对象转移到另一个对象：

```cpp
class SmartBuffer {
    int* data_;
    size_t size_;
public:
    SmartBuffer(SmartBuffer&& other) noexcept
        : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
    }
};
```

### 移动赋值运算符

```cpp
SmartBuffer& operator=(SmartBuffer&& other) noexcept {
    if (this != &other) {
        delete[] data_;
        data_ = other.data_;
        size_ = other.size_;
        other.data_ = nullptr;
        other.size_ = 0;
    }
    return *this;
}
```

### 完美转发

保持参数的值类别：

```cpp
template <typename T>
void wrapper(T&& arg) {
    // 转发 arg，保持其值类别
    target(std::forward<T>(arg));
}
```

## 常见陷阱

### 使用移动后的对象

移动后，源对象处于有效但未指定的状态：

```cpp
std::string s = "hello";
std::string moved = std::move(s);
// s 有效但为空；不要依赖其值
```

### 从 const 对象移动

对 const 对象使用 `std::move` 会产生 const 右值引用，这会退回到拷贝：

```cpp
const std::string s = "hello";
std::string target = std::move(s);  // 拷贝，不是移动！
```

### 移动基本类型

移动整数、指针等没有好处：

```cpp
int x = 42;
int y = std::move(x);  // 与拷贝相同
```

## 右值引用与左值引用对比

| 特性 | 左值引用（`T&`） | 右值引用（`T&&`） |
|------|------------------|-------------------|
| 绑定到 | 具名对象 | 临时对象 |
| 重新绑定 | 不允许 | 不允许 |
| 主要用途 | 函数参数 | 移动语义 |
| 语法 | `T& ref = obj;` | `T&& ref = temp;` |

## 总结

- 右值引用绑定到临时对象
- 它们启用移动语义以实现高效的资源转移
- `std::move` 转换为右值引用，启用移动
- 在移动操作上使用 `noexcept` 以确保异常安全
- 移动后的对象有效但状态未指定

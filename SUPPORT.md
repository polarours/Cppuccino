# Support

Cppuccino is maintained on a best-effort basis.

- **Read the docs first:** <https://polarours.github.io/Cppuccino/>
- **Search existing issues:** <https://github.com/polarours/Cppuccino/issues>
- **Ask a question or report a bug:** open an issue with the relevant template.
- **Report a security problem privately:** see [SECURITY.md](SECURITY.md).

When asking about code, include the compiler and version, the C++ standard,
the operating system, the exact command, and the smallest reproduction you can
produce. “It does not compile” is not enough to reproduce.

There is no paid support, SLA, or private tutoring.

# 观察者防抖

把事件延迟一段时间后再交给处理器的观察者。

## 学习目标

- 在另一个线程上投递事件
- 在分发器消失之前停掉还没发生的投递
- 让处理器和分发器的状态保持一致

## 功能

- `emit()` 安排一次投递；处理函数跑在自己的线程上
- `cancel()` 停掉还没发生的投递
- 析构函数会先取消再等待，所以分发器没了之后不会再有处理函数被调用

## 构建

```bash
cmake -S . -B build && cmake --build build
```

## 测试

```bash
cmake -S . -B build -DBUILD_TESTING=ON && cmake --build build && ctest --test-dir build
```

## 说明

每次 `emit()` 都会被单独投递；延迟只是分发器在调用处理函数之前等的时长。
这个类不会把多个事件合并成一个。

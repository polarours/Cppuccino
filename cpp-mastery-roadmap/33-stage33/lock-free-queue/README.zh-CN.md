# 无锁队列

使用原子操作的无等待队列。

## 学习目标

- 用原子操作搭一个 Michael-Scott 队列
- 只在拥有它的那次交换之后，才把载荷从节点里取走
- 归还一个被弹出的节点时，不把它从读者脚下抽走

## 说明

有两条规则让这个队列站得住，而它们都很容易写错。

**载荷在交换之后才离开节点。** 两个线程可能带着同一个候选值走到同一个
节点上，而只有交换成功的那一个才拥有这个载荷。在交换之前就把值移走，
等于让两个线程同时从同一个对象里往外搬。

**被弹出的节点是"退休"而不是"释放"。** 落后一步的线程可能还在读它当初
看到的那个头节点的 `next` 指针。马上释放它，就等于把那块地砖从读的人脚下
抽走，而那个描述符编号说不定已经归别人所有了。退休的节点在队列销毁时
才被释放。生产级队列会用 hazard pointer 或者基于纪元的回收来更早地
释放它们。

## 构建

```bash
cmake -S . -B build && cmake --build build
```

## 测试

```bash
cmake -S . -B build -DBUILD_TESTING=ON && cmake --build build && ctest --test-dir build
```

# 从这里开始

一次只走一个循环：读一个想法，看它怎么坏，再动手改代码。

1. 先读 [所有权——从这里开始](../docs/中文版/所有权-从这里开始.md)。
2. 接着读 [所有权与生命周期](../docs/中文版/所有权与生命周期.md)
   和 [RAII与异常安全](../docs/中文版/RAII与异常安全.md)。
3. 配套看失败模式：[悬垂指针](../pitfalls/中文版/悬垂指针.md)。
4. 编译证据：[ownership-and-lifetime.cpp](../examples/ownership-and-lifetime.cpp)。
